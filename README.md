# Как редактировать правила?

Правила хранятся в формате `JSON`. Любое изменение здесь автоматически обновляет правила на сайте и внутри игры.

## Важно перед началом
Файл `rules.json` очень строго относится к синтаксису. 
* **Одна пропущенная запятая или лишняя кавычка полностью сломает правила на сервере и сайте.**
* Будьте внимательны при копировании шаблонов. Проверяйте валидность JSON через https://jsonlint.com/

## Как добавить или изменить правило

Все изменения вносятся через создание Pull Request. Напрямую файл сохранить запрещается.

1. Откройте файл `rules.json` в этом репозитории.
2. В правом верхнем углу нажмите на **карандашик** (Edit this file).
3. Внесите необходимые изменения в текст.
4. В самом низу страницы, в блоке **Commit changes**:
   * В первом поле напишите кратко, что вы сделали (например: *Изменено наказание за правило 1.2*).
   * Выберите пункт **Create a new branch for this commit and start a pull request**.
   * Нажмите зеленую кнопку **Propose changes**.
5. На следующей странице нажмите **Create pull request**.
6. Ожидайте. @auriny или леля проверят изменения и применит их. Если вы допустили ошибку в коде, вам напишут об этом в комментариях и, возможно, исправят.

## Форматирование текста (Цвета и стили)

Внутри текста правил мы используем формат MiniMessage. Вы можете раскрашивать текст с помощью специальных тегов. 
* Редактор текстов можно найти здесь: https://webui.advntr.dev/

**Примеры тегов:**
* `<red>Красный текст</red>`
* `<green>Зеленый текст</green>`
* `<bold>Жирный текст</bold>`

**Пример правильного заполнения правила:**
```json
{
  "id": "1.1",
  "text": "Запрещен <red>спам</red> и флуд.",
  "punishment": "Мут от 30 минут"
}
